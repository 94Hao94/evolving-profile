# JEV 独立用途

JEV 总开关、密钥、运行模式与四个用途开关共同决定实际调用。关闭外部 RAG 只影响外部资料审查，不影响内部记忆复核和质量诊断。固定地址、模型与用途默认值来自 `config/jev-provider.json`。

| 用途 | 实际入口 | 边界 |
| --- | --- | --- |
| 内部记忆复核 | User/Agent Recall、Research 和证据回读返回后的 MCP 后处理 | 有界候选摘要、范围和证据状态；不检索、不删候选、不改写事实 |
| 质量诊断 | 同一后处理请求中的诊断问题，以及质量引擎“运行 JEV 诊断” | 基于真实回执；未归因、未测量不是失败；页面加载与刷新不调用模型 |
| 外部 RAG 审查 | 外部资料检索后的审查 | 独立资料来源，受 RAG 总开关与该用途开关共同约束 |
| 风险判断 | 可选只读 MCP 工具 `review_operation_risk` | 默认关闭；返回是否需要确认，不执行操作，不代替宿主或人类授权 |

总开关默认关闭，前三个用途预选，风险判断关闭。用户开启总开关且原模式为关闭时，页面自动选择辅助模式；仍需保存配置。只改 JEV 设置不重启 Embedding/API 服务。

内部记忆的影子模式只保存审计，不把判断结论交给 Agent；辅助/强制模式中的内部判断仍为建议。强制过滤仅限外部 RAG。JEV 的一次判断不证明历史覆盖完整或回答收益。

内部复核与质量诊断可合并在同一请求中；相同有界输入与配置的成功结果缓存十分钟。失败返回确定性规则与未知，不覆盖原候选。调用、用量、模型版本和状态写入 `audit/jev/reviews.jsonl`；密钥和完整原始对话不写入该审计。

网页配置立即使用新部署；已存在的 Codex MCP 进程需要重连或新会话才能加载新增后处理/工具代码。连接成功不表示总开关已经开启，也不表示每个 Prompt 都需要额外判断。
