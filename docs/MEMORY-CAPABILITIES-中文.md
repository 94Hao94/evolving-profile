# EP 能记住什么

[中文 README](../README-中文.md) · [English](MEMORY-CAPABILITIES.md)

EP 将来源材料提炼成用途不同的记忆：项目事实帮助回答“发生过什么”，偏好帮助判断
“怎样协作更合适”，过程经验帮助评估“什么方法可能适用于这里”。原始消息和工具
证据仍是检查提炼结果的依据。

下文说明当前公开实现中的能力，不代表所有宿主都会自动捕获全部来源，也不代表
新安装已有完整记忆，或每次任务都要读取所有层。安装及宿主边界仍以
[部署指南](DEPLOYMENT-中文.md)、[分宿主接入](HOST-SETUP-中文.md)和
[Agent 安装提示词](AGENT-SETUP-中文.md)为准。

## 用户记忆：背景、偏好与原始依据

| 记忆维度 | 保存什么 | 怎样服务任务 |
| --- | --- | --- |
| **事实与状态** | 有来源的事实、计划、约束、纠正和其他陈述背景 | 找回旧决定，区分早期方案与后续修正。 |
| **事件与经历** | 行动、互动、事件背景与陈述结果，并保留来源角色归属 | 重建发生过的事情，避免把助手自述当成独立验证。 |
| **实体与关系** | 人物、机构、地点、项目、概念及其关联记忆，关系须有来源支持 | 查找相关背景，同时区分近邻项目和不同角色。 |
| **时间与情境信息** | 何事、何时、何地、何人、为何，以及发生时段、提及时间和可用元数据 | 核对候选是否属于目标人物、阶段与时间范围。 |
| **归并观察** | 从积累事实中综合出的模式与认识 | 导航反复出现的主题，同时保留综合结果与原始证据的区别。 |
| **五维偏好** | 沟通、学习、分析、协作和交付方式，以及条件与生命周期信息 | 让工作方式适配当前任务。 |
| **融合心智模型** | 跨维度连接已审阅偏好条目的版本化解释 | 参考较完整的工作方式模型，并检查来源、例外和反证。 |
| **情景上下文** | Session/Project 导航、目标、约束、纠正、陈述进展与未决项，以及紧凑、标准、完整三层摘要 | 先找到相关情景，再决定深入哪些细节。 |
| **原始证据** | 可用来源正文、消息定位和有界的 Session/Project 历史 | 核对精确名称、金额、版本、否定和有争议的原话。 |

这些是产品能力维度，不是九种可以互换的数据库事实类型。Bank 实际保存
`world`、`experience`、`observation` 三类记忆单元。提取合约把用户事实、偏好和约束
归为 `world`，把助手行动标为 `assistant`，再映射到存储的 `experience`。
因此，用户经历也可能以事件事实的形式保存在 `world` 中。独立的智能体过程记忆
增加执行过程的结构与门控，不能把它简单理解为 Bank `experience` 的改名。

实现依据：[事实提取](../api/evolving_profile_api/engine/retain/fact_extraction.py)、
[Bank 模型](../api/evolving_profile_api/models.py)、
[情景模型](../host-adapter/lib/scenario_model.py)与
[来源回读](../api/evolving_profile_api/engine/source_facts.py)。

## 偏好：五个维度，保留适用条件

中文名称与偏好界面一致；英文界面使用较短的 Communication、Learning、Reasoning、
Collaboration、Delivery 标签。

| 维度 | 内部标识 | 可提炼的信息示例 |
| --- | --- | --- |
| **沟通与呈现** | `communication` | 语气、措辞、解释篇幅、内容组织与视觉呈现。 |
| **学习与理解** | `learning` | 具体例子、因果解释、学习顺序和复习方法。 |
| **分析与决策** | `reasoning` | 证据要求、比较方法、不确定性与推荐方式。 |
| **执行与协作** | `collaboration` | 主动程度、任务边界、检查点和协作行为。 |
| **质量与交付** | `delivery` | 验证方式、验收标准、输出格式与交付要求。 |

提取合约区分明确偏好、明确可复用要求、推断模式和任务局部要求。纠正、取舍、
不满意的原因都可能成为证据，但任务主题本身不足以构成偏好。推断模式需有独立
来源家族的支持才可发布；一次任务的要求保留其任务范围。

结构化偏好可携带适用条件、例外、行动影响、全局/领域/项目/任务范围、倾向方向、
稳定性或方法时效性、证据引用及来源家族。支持与矛盾次数、新近性输入、修订和
替代关系使变化可检查。即使规范化正文纠正了有依据的语音识别错误，来源引用仍
保留原始文字。

网页提供维度、关系图、表格、时间线、审核状态，以及正文、适用条件和例外的手动
修正。修正不会免除来源核对，也不会扩大执行授权。

融合心智模型将生效偏好版本组合成章节，保留适用条件、例外、反证和引用。
原子跨维度模型合约要求至少两个维度的支持引用，并包含机制、置信度和最后核验
时间。它是可修订的协作解释，不是人格结论，也不能覆盖当前要求。这一偏好融合层
与 Bank 通用观察归并是不同机制。

实现依据：[偏好提取](../guidance/extract_raw_preference_candidates.py)、
[验证与来源合约](../guidance/schemas.py)、[模型发布](../guidance/models.py)、
[偏好界面](../console/src/components/preference-view.tsx)与
[维度及模型关系图](../console/src/lib/preference-graph.ts)。

## 智能体记忆：从执行证据到可复用经验

| 记录或工作流 | 保存什么 | 复用边界 |
| --- | --- | --- |
| **原始轨迹与过程事件** | 可用的执行/工具元数据、来源定位、任务情境与观察到的返回 | 工具成功返回，不证明任务成功。 |
| **过程观察** | 关联来源轨迹的执行行为描述 | 观察是待评估证据，不等于已发布策略。 |
| **过程草稿与失败事件** | 失败特征、尝试的修复与支持轨迹 | 草稿和历史候选保留其证据等级与成熟度。 |
| **修复模式** | 从已验证事件中归纳的重复修复形状 | 晋升为模式需多个已验证事件。 |
| **可复用过程策略** | 从已复现模式派生的策略，附前提、修复动作及验证 | 内部记录类型叫 `skill`，不代表自动安装宿主 Skill。 |
| **能力观测** | 模型/版本在具体任务族和阶段上的独立验证结果 | 一个任务族或阶段的结果，不是通用模型排名。 |
| **迁移与再验证** | 迁移范围、环境/模型指纹、漂移及再验证历史 | 模型或工具变化后，复用仍需证据；传入兼容性条件时执行相应检查。 |
| **任务级辅助** | 显式请求的提示、建议、脚手架或防护 | 当前智能体仍决定是否适用、是否采用。 |

过程合约区分九个执行阶段：**理解、规划、检索、执行、观察、验证、恢复、交付、反思**
（`understand`、`plan`、`retrieve`、`act`、`observe`、`verify`、`recover`、`deliver`、`reflect`）。
记录还可携带任务类型、过程维度标签、模型/版本、环境与模态/能力指纹、前提、结果、
反证、验证证据、派生关系和创建/更新时间。Schema 带维度注册表版本标记，但过程
标签是可扩展字符串，不意味着所有认知能力都有经过认证的提取器。

成熟度区分已观察、已诊断、已修复、已验证、已复现、已泛化与已弃用。历史策略候选
可以留在影子状态，等待独立验证。发布流程支持影子、灰度、发布和回滚，并有评估
门控。要求再验证或已弃用的记录，会从常规过程召回中排除。

这些机制通过记住经验、评估复用来支持适应，不更新模型权重，不保证自主持续提升，
也不证明旧修复能直接用于新的模型和环境。

实现依据：[过程合约、晋升与兼容性](../host-adapter/lib/process_memory.py)、
[评估门控](../host-adapter/lib/process_memory_evaluation.py)、
[有界轨迹捕获与工具入口](../host-adapter/evolving_profile_controller_mcp.py)和
[智能体记忆界面](../console/src/components/agent-memory-view.tsx)。

## 检索、原文与回执

用户 Recall/Research 与智能体 Recall/Research 分别服务各自的记忆路线。情景摘要
帮助选择正确上下文；精确主张可能需要回读原文。`compact → standard → full`
在预算内逐层展开导航细节，即使完整层也不是完整 transcript，更不证明所有历史
纠正都已保留。

可选外部 RAG 对操作者选择的文件进行词法/向量检索、倒数排名融合和可选重排。
外部文档有独立索引与兼容性控制；搜索返回它们，不会让它们自动变成个人偏好或
过去的执行经验。

证据链分别记录**发现候选、准入、返回、观测送达、读取原文和确认答案采用**。
来源引用支撑出处，回执描述可观察事件；两者都不能单独证明当前事实有效或答案
质量。归属缺失、来源不可用、模型身份未知和送达未测量，都应保留为可见限制。
使用记忆前仍需核对当前要求、时间、来源版本以及模型和工具的适用性。

任务级流程见 [README 工作逻辑](../README-中文.md#ep-how-it-works)，
当前发行包验证与限制见[补丁说明](RELEASE-NOTES-5.1.1.md)。
