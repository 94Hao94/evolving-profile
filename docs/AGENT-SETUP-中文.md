# 给不同Agent的“安装＋会使用”提示词

[English](AGENT-SETUP.md) · [候选包安装](CANDIDATE-SETUP.md) · [日常使用协议](AGENT-USAGE-中文.md)

把精确v5.1.2-rc.1标签或对应命名核验归档及实际目录交给Agent，先读VERSION与通道。
不能让它克隆旧分支，再声称装了这个新版本。选择真实宿主入口，不只看模型品牌。

## 所有入口共同使用的完整要求

下面通用段落与对应宿主补充段一起复制：

```text
请使用ccygod/evolving-profile-2.2的精确v5.1.2-rc.1标签或对应命名核验归档，
核对VERSION与发行清单，不要用旧远端分支替代。
先读README、CANDIDATE-SETUP、DEPLOYMENT-中文、HOST-SETUP-中文、宿主准备说明，
以及AGENT-USAGE-中文。确认系统、本机/WSL/远端、权限、端口与已有配置。
先做包与版本预检并从本目录构建；Bash安装器只构建，不代表服务或客户端已启动。
安全配置我自己的数据库、聊天和向量服务；不编造密钥、不复制作者状态，不默认
聊天Coding Plan包含向量服务。只启动已获授权的后端/Controller/Console并打开网页。
先核对实际运行目录/构建，再按CANDIDATE-SETUP预览并显式投影版本清单到同一个
state root，不提前把旧进程贴成新版本。
备份并合并一个正确的MCP入口，保留其他配置和我后来修改的内容，使用真实绝对路径，
遵守客户端信任与批准流程。不擅自启用RAG/JEV/云/捕获，不导入全历史、写假记忆、
安装其他客户端、公开端口、降低安全限制或发布GitHub。
连接后按AGENT-USAGE选择偏好、用户历史、智能体经验、情景或外部资料路线，读实际
schema。使用真实本轮绑定；导航生成的ID不等于可信Hook身份，不借用其他会话。
分别报告构建、服务、网页、工具、绑定、接收、捕获、提炼的真实结果。缺权限、
凭据或能力就说明具体缺口和交接步骤，工具列表成功不能冒充全链路通过。
```

这是用户委托的安装范围；文档本身不授权改配置、记录私人任务或给其他客户端发任务。

## Codex桌面端/CLI补充

```text
在当前Codex入口检查现有MCP与Hook，备份并合并，处理旧别名避免重复；保留其他handler，
遵守正常信任。不要整份复制作者Hook。当前会话核对真实工具、本轮绑定与Bank，
新Bank为空合法。只有我允许自动捕获时，才用一个自然任务核对来源身份、去重、队列、
提炼完成和回执，再安排需要的自有worker。独立准备档案不代表已有连接已热升级。
```

## Claude Code CLI补充

```text
在当前Claude CLI先查实际help、配置范围和已有入口，再按CLI配方注册一次EP。
在这个CLI内验证工具及策略允许的绑定/无绑定读取；不复制Codex留存脚本，不让Codex
扫描器去抓Claude对话。我批准后才在宿主支持的项目规则中引用AGENT-USAGE，不覆盖
已有规则。原生生命周期、来源与接收未测时如实标明，不能因注册成功写成完成。
```

## Claude桌面端，本地Code页补充

```text
确认是当前桌面本地Code，而不是普通Chat、云端或SSH。复用正确的MCP配置，不重复注册；
工具必须在这次桌面会话验证，另一CLI成功不能代替。按AGENT-USAGE使用；没有原生
来源、生命周期证据与我的允许，就不启用自动捕获。
```

## Claude Desktop普通Chat补充

```text
连接我已运行的EP，按普通Chat的本地MCP配方处理。没有终端/浏览器权限就把后端安装
交给获授权的CLI/Code操作者，不声称普通Chat已部署服务。阅读AGENT-USAGE，发现真实
工具，只做策略允许的读取，不编造Hook绑定。不宣称有Code Hook、自动抓取全部聊天
或发行包已经包含.mcpb一键安装器。
```

## Hermes补充

```text
检查当前Hermes实际MCP/API配置与能力，再选择配方；保留它自己的事件、来源格式与规则，
不要假扮Codex。通过宿主支持的说明机制引用AGENT-USAGE。先验证显式读取，自动
生命周期和宿主接收只有原生证据后才判定通过。
```

## WorkBuddy补充

```text
只有已安装WorkBuddy且我允许注册时才接入。先用host workbuddy生成doctor与配置预览；
EP侧探针不是WorkBuddy任务。审阅目标JSON，备份合并并走客户端批准。
支持时引用AGENT-USAGE；同名Hook不证明来源捕获兼容，捕获保持关闭，缺绑定如实报告。
没安装就只准备配置，不擅自安装客户端。
```

## 豆包工作补充

```text
针对实际本地豆包工作入口，配置由宿主管理，不编造私人配置文件路径。先生成host
doubao_work指导，与我审阅插件command/args/env或认证HTTP方案。为当前任务启用/选择
可信插件；宿主支持时通过说明/Skill引用AGENT-USAGE，但插件匹配或Skill不保证每轮触发。
不为了证明准备完成就发真实任务、安装Skill或开启捕获。
```

## 通用MCP、Windows、WSL、远端补充

```text
按真实系统/模式接入；Windows准备说明不是完整原生安装认证。不能混用Windows/Linux
路径、默认localhost转发或绕过宿主安全。核对工具schema、范围与说明加载机制。
没有绑定就不编造，只用允许读取的能力；生命周期、来源、送达未知时保留未知。
```

## 安装完成的回复应包含

真实路径/版本、服务端口及状态、网页地址与检查项、当前宿主工具证据和所用Bank；
捕获是否开启及是否真测。准备、配置、协议、宿主接收、回答采用分开列。
保留备份/回退说明；缺少凭据或能力就列具体缺口，不显示密钥、不编造完成。
