# Console 多语言全局审计

目标：英文页面显示英文，简体中文页面显示中文；用户原文、项目名、路径、标签值、模型名和技术工具键保持原样。

## 页面验收清单

- [x] 用户记忆主页面
- [x] 文档列表和文档详情弹窗
- [x] Recall 检索分析器
- [x] 智能体记忆
- [ ] 链路页：中部节点和详情面板
- [ ] 运行配置：概览、模块、RAG、Provider、备份、情景摘要
- [ ] 情景摘要详情
- [ ] 实体、记忆详情和审计弹窗
- [ ] 英文/中文逐页切换回归

## 判定规则

1. 英文页面出现中文界面文案即失败；真实数据和用户内容不算失败。
2. 中文页面出现英文界面文案即失败；模型名、Provider、MCP 工具名、路径和技术字段不算失败。
3. 每个页面至少检查首屏、详情/弹窗、空状态、错误状态和滚动区域。
4. 修改后运行 Console 测试、生产构建，并在 9999 实例重新验证。
